# ubuntu-24.04

Use it with `zode/ubuntu-24.04`. The Zode base image (Ubuntu 24.04 LTS,
built by `deploy/node/make-base.sh` in zode-dev/zoded) as a named line,
plus the security updates published since the base was built. Old size
names (`small-v8`, ...) resolve to this line (REQ-081).

The publish workflow replaces this file with the software list after the
first release.
